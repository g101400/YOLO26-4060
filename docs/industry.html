工业场景应用

基于 YOLO-Lite 四系列（v5/v8/v11/v26）的端侧检测能力，以下场景已在工程上可落地

① 工业质检（表面缺陷 / 零件缺漏）

PCB 焊点缺失、金属划痕、药板缺粒、食品包装完整性。用 v11/v26 抓小目标与遮挡件，端侧实时剔废。
小目标低延迟可解释 配合「VLM 分析」输出缺陷成因与建议，生成人能读的质检报告。

② 安全生产 / 安防（人-物行为）

未戴安全帽/工服、人员闯入危险区、烟火、车辆违停。手机或固定摄像头即可部署，v8 生态成熟、模型现成。
实时边缘 报警可本地触发，无需上云。

③ 农业（病虫害 / 长势 / 畜禽）

航拍或田间摄像头识别病斑、害虫、果蔬成熟度。v11/v26 对小目标（虫卵、早期病斑）更稳。
小目标复杂背景 无人机 NVR 可直接跑 ncnn。

④ 交通 / 物流（车流 / 包裹 / 车牌）

路口车流统计、包裹分拣、车位占用、车牌/箱体识别。v26 低功耗适合长期值守摄像头。
低功耗易部署 无 NMS 让导出到 INT8/TFLite 更干净。

⑤ 零售 / 仓储（货架 / 盘点）

货架陈列核对、商品识别、库存盘点。端侧出框 + VLM 做「货架空缺/价签错放」自然语言告警。
VLM 闭环 见「结合大模型改进」。

⑥ 机器人 / 无人机（感知前端）

抓取前定位、避障、巡检测框。YOLO 当感知前端，文本指令 → 检测 → 决策 → 执行的智能体闭环。
智能体端侧实时

选型速记

• 要现成多任务、团队快上手 → v8。
• 小目标/遮挡/复杂背景且要省算力 → v11。
• 纯边缘、低功耗、小目标密集、易部署 → v26。
• 接手存量或不追新 → v5。
