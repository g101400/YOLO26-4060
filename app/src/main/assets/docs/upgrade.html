四、检查更新

app 右上角菜单 →「知识文档」→「软件升级」页内点「检查更新」按钮，会直接打开本系列对应的 GitHub Releases 页面，比对版本号手动下载安装。

五、知识文档同步

「知识文档」各页支持「同步最新」：联网时从本仓库 docs/ 拉取最新版覆盖本地内置内容，便于随研究深入与软件更新持续更新（无需发版）。
